# decentralized-campus-mesh
The Decentralized Campus Content and Resource Mesh (DCCRM) is a peer-to-peer networking architecture designed to eliminate bandwidth constraints 
and central internet dependency in academic environments like university hostels and department labs.
When thousands of students concurrently attempt to download heavy study materials, video lectures, or software packages, traditional campus networks
frequently bottleneck or fail completely.
if external internet links drop. DCCRM solves this by enabling student devices in close physical proximity to form an ad-hoc local mesh network, 
bypassing external routers to exchange files directly over high-speed local Wi-FI
